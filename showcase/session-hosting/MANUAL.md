# 会话托管 · 说明书

> 平板继续跑 Claude 会话，手机远程看文字、发消息、插话、停止、回答授权卡。
> 执行环境、终端、工作区文件始终留在主机；中转服务器只转发端到端加密的密文。
>
> 配图见 `assets/`；可交互的真实演示见同目录 `index.html`（启动 `sh start.sh` 后访问 `http://127.0.0.1:17800/`）。

---

## 0. 这是什么

会话托管把「正在运行的 Claude 会话」开放给另一台设备**观察和有限控制**，而不是把整台设备远程桌面化。

```
┌───────────────┐   AES-256-GCM 密文   ┌──────────────┐   AES-256-GCM 密文   ┌───────────────┐
│  平板 · 主机   │ ──────────────────▶ │  中转服务器   │ ◀────────────────── │ 手机 · 控制端  │
│ Claude/终端/文件│ ◀────────────────── │ 只转发不透明密文│ ──────────────────▶ │ 原聊天页组件   │
│ secret 只在此  │                     │ 落盘仅令牌哈希 │                     │ secret 只在此  │
└───────────────┘                     └──────────────┘                     └───────────────┘
        TLS 在外层保护连接；AES-256-GCM 在内层保护内容。服务器两层都解不开内容。
```

主机在托管面板里**逐个会话**开启托管；控制端凭**配对码**连接。配对码相当于这些会话的控制权，只给信任的设备。没有开启托管的会话对远端完全不可见。

**一句话区分**：这不是远程桌面——没有文件同步、没有终端代理、不能远程点安卓系统弹窗、不能关机后继续。它同步的是「会话文字 + 会话控制」。

## 1. 能做什么 / 不能做什么

远程可以：
- 查看已托管会话的历史与实时输出（原聊天组件渲染）
- 发送普通文字消息、运行中插话
- 停止当前轮（挂起该会话排队消息）
- 回答授权卡：允许 / 拒绝 / 拒绝并停止
- 回答 AskUserQuestion 选择题、确认 ExitPlanMode 计划
- 翻历史窗口、书签、删除/撤销、分叉/仅对话回退（主机执行）
- 看主机口径的上下文 / 模型 / 权限 / 统计 / 费用

远程不可以：
- 读未托管会话、读工作区文件、传二进制
- 发 `/` 斜杠命令（改全局配置的请在主机做）
- 「始终允许」、切全局权限模式
- 批准被截短（`cut`）的授权卡——只能拒绝或到主机看全文
- 远程确认安卓安装器 / Shizuku / 系统安全弹窗
- 任意路径访问、任意 HTTP 转发、全局 abort

## 2. 安全模型

### 2.1 端到端加密，中转零明文
主机生成独立 32 字节 `secret`。每个包用 **AES-256-GCM**：随机 12 字节 IV、16 字节认证标签，封装为 `base64url(IV‖tag‖ciphertext)`。附加认证数据 `AAD = cc-host-v1:{room}:{id}:{direction}` 把密文绑定到房间、请求编号和方向，防跨房间/跨方向重放。`secret` 只存在于配对码里，**从不经过服务器**。

中转服务器只看到不透明密文与随机编号；持久化只落 host/client 令牌的 **SHA-256**，不落明文、不落密钥、不记正文到日志。演示页「中转视角」会把经过的密文片段直接展示给你看。

### 2.2 配对码 = 控制权
格式 `CCH1.` + base64url(JSON `{v,url,room,clientToken,secret}`)。持有它即可操作所有已托管会话，因此默认隐藏、点击才显示，勿截图公开、用后清剪贴板。生产只允许 HTTPS 源站地址（测试显式允许回环）。

### 2.3 凭据分离与吊销
建房返回 `hostToken` 与 `clientToken` 两把独立凭据：主机用 hostToken 轮询/回复，控制端用 clientToken 发 RPC，服务器据此隔离双方。主机「吊销所有配对」删除房间、双方凭据立即失效；「取消托管」立即撤销该会话 grant；「暂停托管」只停远程访问、不停本地任务。

### 2.4 写操作幂等 + 授权绑定
每个写请求（send/stop/answer/message）带唯一 32 位 hex 编号。主机**先持久化预占编号再调用上游**：回执丢失或网络重试时，同编号只返回第一次结果，绝不执行第二遍。编号台账绑定本次 `boot` 与该会话 `grant`；主机重启或重新托管后旧编号自然失效。操作身份绑定 op/sessionId/boot/grant/args，不因运输 expires 续期而重新执行。

> **连接故障不自动重发写操作**：失败时先刷新会话核对，避免把「回执丢了」误判成「没执行」。相同请求重试必须沿用原编号与原参数。

## 5. 同步机制

控制端不发高频轮询、不是 SSE。`watch` 请求挂在主机事件总线上：有变化才醒来，合并 80ms 内连续事件回一帧**增量**；无变化挂满 8 秒回心跳。文字增量只传追加部分（`tailPatch`），不重发整段；历史/范围失效才 `reset` 全量对齐。

```
控制端                中转                主机事件总线
  │ watch(revision)密文 │                    │
  │──────────────────▶│───────────────────▶│
  │                   │  delta 事件唤醒→增量帧│
  │◀──────────────────│◀───────────────────│
  │ watch(新revision)  │                    │
  │──────────────────▶│───────────────────▶│
  │                   │ 无变化挂8s→unchanged │
  │◀──────────────────│◀───────────────────│
```

面板可见时配置约 2.5s poll 一次；聊天页用事件驱动 watch。切页/关闭用 AbortController 取消；失联立即禁用控制按钮（12s watchdog），成功同步后恢复。读历史不替换正在看的段落、不抢焦点，保留滚动位置与草稿。

主机 `list.history=1` 支持固定 from/to/size/exclude 的双向字节范围历史窗口（MAX_PAGES=8）；前翻传 before/exclude、后翻传 after/until/exclude。内容或范围失效丢旧偏移重新同步。旧主机缺能力时显示尾页但翻历史要求升级。

侧栏「远程」分组直接列出已配对设备的托管会话（运行/待答/待命圆点 + 设备名），点一下进入。分组被上游 `renderSideRecent` 整块重写后由 MutationObserver/定时检查补回；侧栏没打开时零请求零重画。

*图 6-1 侧栏「远程」分组。首次进入远程会话前若未缓存列表，返回一次后即出现。*

![从侧栏点回远程会话](assets/p11-sidebar-reenter.png)

## 7. 保活与更新

- 主机保持供电、联网，按系统设置允许后台运行；不代用户开 Shizuku 或改电池白名单。
- 原生前台服务保持网关；有托管会话且启用时，已验签的原生状态查询持有**托管租约**，防止普通划掉任务卡被当完全空闲。不伪造运行任务标记。
- 系统强杀、强行停止、关机、重启后仍需重新打开主机应用；纯 JS 模块不保证这些情形自动恢复。
- 更新应用或工具包前先「暂停托管连接」，否则原生更新器可能为保护托管延后安装。

> **不要承诺关机后继续**：应用退后台可继续，但系统杀进程/断网/关机后无法远程控制。

## 8. 自建中转服务

中转是独立 Python aiohttp 服务，前缀 `/cc-host/v1`，只监听 `127.0.0.1:7865`，接在现有 Caddy 443 后。只中转不透明密文，无文件/终端代理。

```
CC_HOST_ENROLL_TOKEN=<43字符 base64url 强随机>
CC_HOST_STATE=/var/lib/cc-host-relay/rooms.json   # 0600，仅令牌 SHA256
CC_HOST_PORT=7865
CC_HOST_BIND=127.0.0.1
```

- 非 root 用户运行（systemd `cc-host-relay.service`）；环境文件 0600。
- Caddy 独立反代 `/cc-host/v1/*`，不迁移原有路由；改配置前备份、验证后重启。
- 健康检查 `GET /cc-host/v1/health` → `{ok:true,protocol:1}`，公开、不泄露房间。
- 拒绝带 Origin 的请求（只接受本地网关服务端 fetch）；禁止重定向；不接受 query token。
- 退役：先暂停/吊销主机，再删独立路由、验证配置、重启 Caddy、停中转；不要用旧整份配置覆盖新增配置。

## 9. 协议与接口参考

### 9.1 中转端点
| 端点 | 凭据 | 说明 |
|---|---|---|
| POST /rooms | enrollToken | 建房 → {room,hostToken,clientToken}；最多 32 房间；持久化成功才返回 |
| DELETE /rooms/:room | hostToken | 吊销双方凭据、取消等候请求 |
| GET /rooms/:room/poll | hostToken | ≤20s 长轮询 → {requests:[{id,packet}]}；一次≤4；只允许一个 poll（第二个 409） |
| POST /rooms/:room/rpc | clientToken | {id,packet} 入主机队列，≤25s 等回执；过期 504；同 id 活跃重复 409 |
| POST /rooms/:room/reply | hostToken | {id,packet}；未知/过期 id 409 |

限制：JSON body ≤4MiB、密文串 ≤3MiB；每房间 ≤16 未完成 RPC、≤1 poll；全局 ≤64 未完成。错误统一 `{error}`；`Cache-Control: no-store`。

### 9.2 托管 RPC op（控制端 → 主机）
| op | 类型 | 说明 |
|---|---|---|
| list | 读 | {boot,name,sync,resume,history,actions,info,sessions[]}；只列已托管会话；成功=此刻主机在线 |
| session | 读 | 历史页 + live + run/perms/queue/info/range/marks；翻页 before/after/until/exclude |
| watch | 读 | 事件驱动增量长轮询；revision/immediate；reset 或 delta 或 unchanged |
| send | 写 | {message,inject}；1–24000 字；拒绝 / 斜杠命令；幂等 |
| stop | 写 | {runId}；只停这一会话、挂起其队列 |
| answer | 写 | {runId,id,behavior,answers,message,interrupt}；无始终允许；cut 禁止 allow |
| message | 写 | {action:delete/undo/fork/rewind/mark,revision,…}；主机执行、核对历史指纹 |

### 9.3 本地 UI 接口（同源、原网关鉴权）
`/api/hosting/`：status、local-sessions、host、host-toggle、host-remove、pair-code、share、pair、forget、rpc。凭据与会话文字不缓存；不增加公开入口。

## 10. 已知限制（如实）

- 双真实安卓设备的 WebView / 键盘 / 异网 / 后台保活验收仍待安装后完成；无头浏览器与回环延迟不代表实网最差时延。
- 首次网络快照有传输与一次性构建成本；文本/单次/总预算有摘要限额，不承诺超限全文或二进制传输。
- 主机队列与后台任务只读显示；撤回/清队列/停单个后台任务需回主机；整轮停止可用原发送键。
- 远程页打开期间侧栏后台索引不刷新；首次进入远程会话前若未缓存列表，返回一次后分组才出现。
- 本机侧栏运行点在远程期间保留最后本机状态，退出后重新对账；不把主机运行标为手机同号会话。
