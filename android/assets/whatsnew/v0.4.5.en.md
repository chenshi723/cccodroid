This release lets the file viewer handle very long documents, and fixes PDFs not opening on older Android WebViews.

## Long documents

- The size limit for opening Markdown and text files goes from 2 MB to 16 MB, so manuscripts of millions of characters open and can be edited.
- Long Markdown previews render in sections: only what is near the screen is laid out, and sections far away are released. On a test file of 2 million Chinese characters, the preview opens in about 0.1 s and scrolls smoothly.
- The word count in the editor only recounts the lines you changed, and moving the cursor no longer triggers a recount. For large files the first count runs in the background and the top bar shows "Counting words…" meanwhile.
- Unsaved drafts are now kept in IndexedDB, so long documents fit. Drafts left by older versions can still be restored.

## PDF

- Fixed `Promise.withResolvers is not a function` when opening PDFs on systems with an older WebView (for example Chrome 104 on Android 13). The missing features are now filled in before the PDF viewer loads.

## Other

- Help and the What's New card now link to the cccodroid society Discord server. English and Chinese are both welcome.
