This release fixes two layout problems that showed up when you have many providers set up, or use a language with longer words such as Russian.

## Fixes

- **Too many providers squeezed out the model list.** In "Model & thinking effort" under the input bar, the provider row used to wrap. With many providers it grew to several rows and left the model list below only a sliver of space. It's now a single row you swipe sideways, scrolled to the provider in use when it opens. The thinking effort row works the same way.
- **Buttons in Settings ran past the edge.** On a tablet in landscape with a long-word language such as Russian, buttons like "Check for updates" and "Revert" stuck out of the settings column. Long labels now wrap onto two lines inside the button.

We also went through every page and popup in several languages and screen widths, and found nothing else running past the edge.
