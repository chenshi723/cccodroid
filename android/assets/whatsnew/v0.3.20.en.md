A round of polish: a long list of background commands can now be folded away, HTML previews load assets from parent folders, and command descriptions are translated in every UI language.

## Background tasks fold

- The "running in background" list above the input box used to take over half the screen once several commands piled up, with no way to hide it. With two or more it now folds into one line — the count and the newest task — and a tap opens the full list.
- When open it takes at most about a third of the screen and scrolls beyond that. It used to show only four; now every task is listed and each can be stopped.
- A single task still shows as one line with its Stop button. The app remembers whether you left the list open.

## HTML preview

- When a page sits in a subfolder and its styles and images live one level up (say `../assets/site.css`), the preview used to drop all of them. It now looks up to three folders higher, so generated websites preview properly.
- What a preview can read is as limited as before: keys and private folders stay off limits.

## Fixes

- Command descriptions on the Capabilities page and in the slash-command list showed in Chinese in other UI languages; all nine languages now have them.
- In portrait on a phone, the long description under Permission mode (Settings → Claude behavior) made the whole page scroll sideways.
