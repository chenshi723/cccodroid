This release fills in Markdown in chat: math, code highlighting, strikethrough and task lists. All of it was requested by [hye45402-pixel](https://github.com/hye45402-pixel) in discussion #18, with a careful, detailed list. Thank you for helping round out the app.

## Math

- LaTeX in replies is now typeset: inline `$…$` and `\(…\)`, display `$$…$$` and `\[…\]`, including multi-line blocks.
- The math library loads only when a reply actually contains a formula, so normal chats stay fast.
- Ordinary dollar signs such as `$5 to $10`, `$PATH` or `$HOME` are not treated as math.

## Code blocks

- The language name (python, bash, js, …) is shown at the top of each code block.
- Syntax highlighting for about thirty common languages, with separate dark and light colors. The copy button still copies plain text.

## Other formatting

- Strikethrough `~~text~~` and bold italic `***text***`.
- Task lists `- [ ]` / `- [x]` render as checkboxes.
- Markdown files opened in the file viewer get the same support in preview.

## Markdown editor

- Math is typeset in edit mode too: lines without the cursor show the rendered formula, and tapping one reveals the source. The file itself is never changed.
- The ``` fences of a code block are hidden when the cursor is elsewhere, leaving just the language name.
