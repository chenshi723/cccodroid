This release fixes one problem: with some relay endpoints, a finished answer was taken back and written out again.

## Finished answers are no longer retracted and rewritten

- Some relays close the connection at the end of an answer without sending the final "done" signal. Claude Code treats that as a cut-off and asks the model to answer again, up to three times, and may finish with "Connection lost mid-response". On screen the answer was written, removed and written again, and the provider billed the extra calls.
- Requests to custom endpoints now go through a small local relay inside the app. When the answer has fully arrived and only the closing signal is missing, the relay adds it, so Claude Code sees a normal finish. Answers that really were cut off mid-way are left alone, and Claude Code retries them as before.
- Built-in providers and the official account don't go through this relay.
