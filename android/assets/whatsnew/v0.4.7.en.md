This release fills in the model providers you can connect to directly, and brings in our first community contribution: Claude's working status on the ColorOS Fluid Cloud island.

## New

- **Nine more model providers**: MiniMax, Volcengine Ark (Doubao Coding Plan), Xiaomi MiMo, StepFun, Baidu Qianfan, Tencent Hunyuan (TokenHub), Meituan LongCat, xAI Grok and Meta Muse. Each is the provider's own official Anthropic-compatible endpoint, filled in from their documentation; where a provider has China/international or pay-as-you-go/plan variants, just pick the line. Counting Anthropic, that makes 14 built-in model providers. Third-party aggregators such as OpenRouter are not built in for now; use a custom endpoint if you need one.
- **Work Island (ColorOS)**: install the separate [Work Island](https://github.com/STUTTEFRFIX/WorkIsland-Android) app and turn on the switch in Settings, and "working", "waiting for your confirmation" and "done" appear on the ColorOS 16 Fluid Cloud island, hiding 8 seconds after a task finishes. Off by default; so far tested only on ColorOS 16 / Android 16. Thanks to @STUTTEFRFIX for the contribution.

## Fixes

- **Memory manager showed "0 background apps can be stopped"**: when Shizuku wasn't running or wasn't authorized, the memory manager treated that as nothing to stop. It now says Shizuku is unavailable.
- When the interface language isn't Chinese, provider, line and model names are all shown in English.
