这一版专修一个问题：用某些中转站接口时，回答说完了又被整段撤回、重新输出一遍。

## 回答说完不再被撤回重答

- 有的中转站在回答结尾不发「说完了」的收尾信号就断开连接。Claude Code 会把这当成中途掐断，再请求一次让模型重答，最多连着来三遍，最后还可能报「Connection lost mid-response」。界面上看就是回答写完、被撤回、再写一遍，厂商那边也会多记几次调用。
- 现在自定义接口的请求会先经过应用内的一层本地转发：回答已经完整出来、只差结尾信号时，由它补上，Claude Code 就当作正常结束。真断在半截的回答不补，照旧交给 Claude Code 自己重试。
- 预置的接口和官方账户不经过这一层。
