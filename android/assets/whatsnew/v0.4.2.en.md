This release fixes several problems reported in the group chat and makes downloads much less likely to stall. The Claude Code version picker also starts showing which versions have been tested on a real device.

## Updates no longer stall at 0%

- When GitHub was reachable but crawling, the app kept waiting and the screen sat at "Downloading 0%". Now a route that delivers less than 600 KB in 30 seconds counts as failed and the next one is tried. If every route is slow, the download keeps going slowly instead of failing.
- App updates have a new direct route, dl.cccodroid.net (not through Cloudflare). The order is GitHub → cccodroid.net → dl.cccodroid.net → gh-proxy.
- Progress refreshes every second and shows "0 MB" at the start instead of a blank.

## No more duplicated answers

- When the connection dropped mid-answer and Claude Code retried, the half-finished first attempt stayed on screen, so the answer looked like it was written twice. The unfinished part is now removed and only the complete answer remains.

## Components page opens instantly

- The Components page used to take a while every time the app was reopened. It now shows the last saved list right away and refreshes in the background, and switches to the mirror sooner when GitHub is slow.

## Claude Code versions: Verified / Known issue

- In Settings → Updates → Claude Code version, versions the maintainer has run on a real device are marked "Verified", followed by the device and Android version. Versions confirmed broken on cccodroid show the reason, and you're asked to confirm before switching to one.
- If your channel moves to a version with a known issue, auto-update holds off. You can still install it yourself.
- What the verification covers and what it doesn't: docs/claude-code-versions.md.

## Scheduled tasks on a subscription account: off by default

- Scheduled tasks that would run on a subscription account (official login) no longer run by default. To turn them on, go to "Subscription account" at the bottom of the Scheduled tasks page and accept the notice: unattended use is governed by Anthropic's terms. Providers using an API key are not affected.

## Also

- New permissions guide: what each permission is for, when you're asked and what happens if you say no. See docs/permissions.md.
- The gateway now has automated tests that run before every build.
