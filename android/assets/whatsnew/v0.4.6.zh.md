这一版是安全修复，建议尽快更新。问题来自一次代码审计，集中在「HTML 预览」：在应用里打开一个不可信的网页文件时，它能做的事比应该的多。

## 修复

- **预览页能读到别的文件**：之前在共享存储里预览一个 HTML，页面里的脚本可以往上级目录找，最远能读到相册、下载等整个共享存储。现在预览页只能读它所在目录、以及打开时就确定下来的几层上级目录，不会进入存储根、Download、DCIM 这类大目录。网页引用 `../assets` 这类上级资源照常能加载。
- **预览页能调用应用的原生功能**：之前预览页里的脚本可以直接调用应用的卸载、写剪贴板、打开链接等功能。现在这些功能都要带一个口令，口令只交给应用自己的界面，预览页拿不到。
- **一个畸形请求能让网关退出**：本机任何应用发一个特殊构造的请求，就能让网关崩溃重启。现在这类请求直接返回错误，网关不受影响。

## 加固

- 从官方下载 Claude Code 时也要验 Anthropic 的签名，不再只靠 HTTPS。没有签名文件的老版本会改用 npm 签名校验，照样能装。
- 界面的 WebView 关掉了读取本地文件（file://）的权限。
- 内置浏览器识别本机地址更严格，`127.1`、`2130706433` 这类写法也拦得住。
- 打包流程用到的 GitHub Actions 改为固定到具体提交。
