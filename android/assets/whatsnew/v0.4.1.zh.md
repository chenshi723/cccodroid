这一版专门让下载变快：大文件分几路同时下，GitHub 不顺时还多了一条加速线路。来自讨论区 #15 的建议。

## 下载提速

- 工具包、模块、组件包、Claude Code 和应用更新，文件稍大（16 MB 以上）时会分成最多 4 段同时下。单条连接被限速的线路提升最明显：实测走 cccodroid.net 镜像快了三到五倍，走 GitHub 快了一半左右。具体能快多少，要看你的网络。
- 断点续传照常可用：下到一半断网、被系统杀掉，或者中途换了线路，都会按每段已下的进度接着下，不用从头再来。下载线路不支持分段时，自动退回单线下载。

## GitHub 加速线路

- GitHub 和镜像都下不动时，最后会再试一次 gh-proxy.com 加速。
- 不管从哪条线路下，文件都照样核对 sha256 和签名，对不上就不用。所以借用第三方的加速线路也不影响安全。
