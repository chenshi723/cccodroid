After twenty-one 0.3.x releases, this one starts 0.4.x. It fixes a few things people in the group reported: PDFs that wouldn't open on older phones, a spot on the start screen where swiping didn't open the sidebar, and folded task lists that left other rows showing. Claude also gets your phone's chip right now.

## Claude knows your device

- Asked which chip the phone has, Claude used to guess from the model number; a Dimensity 700 was once called a Snapdragon 888. Every chat now carries the model, Android version, chip, CPU clocks, GPU and memory as read from the system.
- Claude goes by those readings. When all it has is a platform code (such as MediaTek's mt6833) and it isn't sure which chip that is, it says the code instead of guessing.

## Folding above the input box

- Folding the task list now folds the goal and background tasks with it, and the list's row shows "N more". Unfold it and everything is back. A single background task couldn't fold before, so it stayed visible under a folded list.

## Fixes

- PDFs wouldn't open on phones with an older system WebView. The app now uses the same pdf.js version in its build for older browsers, and closing a PDF no longer calls a method the new version removed.
- In portrait on a phone, swiping across the input box, or the space below it, on a new chat's start screen didn't pull out the sidebar.
