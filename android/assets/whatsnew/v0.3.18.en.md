You can now take a photo and send it straight to Claude, and the Download button in file previews has become Share.

## Take a photo

- The top row of ＋ next to the input box is now: Attach file, Take photo, Screenshot, Browse files.
- Tap Take photo to open the system camera; confirm the shot and it lands in the attachment bar. No camera permission is needed.
- Photos are scaled to 2048 px on the long side and turned upright before they're attached. A multi-megabyte original usually ends up a few hundred KB — text stays readable and it stays within providers' image limits.
- "Screenshot in 5 s" no longer has its own tile: **long-press Screenshot** instead. Hold for half a second, switch to the app you want to capture, and you'll be brought back afterwards.

## Previews share instead of download

- When you preview a file in the app (md, docx, PDF, code and so on), the download button in the top right is now Share — the same icon as Forward in the chat. It opens the system share sheet so you can send the file to another app. The file is already on your phone, so there's no point saving another copy.
- Files that can't be previewed, and images opened from the chat, also get Share instead of Download.
- Files in the workspace and on /sdcard can be shared.

## Other

- The glibc loader used when building the APK is now kept in the source tree, so builds no longer depend on an external download. The README now lists its license (LGPL).
