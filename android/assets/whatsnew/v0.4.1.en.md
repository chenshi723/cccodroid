This release is about faster downloads: big files now come down over several connections at once, and there's one more fallback route when GitHub is slow. The idea came from discussion #15.

## Faster downloads

- The devkit, its modules, component packages, Claude Code and app updates are split into up to four segments fetched in parallel once a file is 16 MB or larger. Routes that throttle each connection gain the most: in our tests the cccodroid.net mirror got three to five times faster and GitHub about half again as fast. How much you gain depends on your network.
- Resuming still works. If the network drops, the system kills the app or the download switches routes partway, each segment picks up where it stopped instead of starting over. A route that can't serve segments falls back to a single connection.

## GitHub fallback route

- When both GitHub and the mirror struggle, the app tries gh-proxy.com as a last resort.
- Whatever the route, every file is still checked against its sha256 and signatures, and a mismatch is thrown away, so a third-party route doesn't weaken security.
