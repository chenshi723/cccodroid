这一版修了群友报的几个问题，下载更新也更不容易卡住。另外，Claude Code 的版本选单开始标出哪些版本在真机上验过。

## 下载更新不再卡在 0%

- 以前 GitHub 连得上、但慢得像没动时，应用会一直等下去，界面停在「下载中 0%」。现在 30 秒不到 600 KB 就当这条线路不行，自动换下一条。所有线路都慢的话，就接着慢慢下，不会报错。
- 应用更新多了一条直连线路 dl.cccodroid.net（不经 Cloudflare），顺序是 GitHub → cccodroid.net → dl.cccodroid.net → gh-proxy。
- 下载进度每秒刷新一次，刚开始时显示「0 MB」，不再是一片空白。

## 回答不再重复

- 网络中途断了、Claude Code 自动重试时，前一次说了一半的话会留在界面上，看起来像同一段回答输出了两遍。现在没说完的那半截会被撤掉，只留最后完整的那次。

## 组件页秒开

- 每次重开应用，组件页都要等好一会儿才出来。现在先显示上次存下的列表，后台再去更新；GitHub 拉不下来时会更快换到镜像。

## Claude Code 版本：已验证 / 有已知问题

- 在「设置 → 更新 → Claude Code 版本」里，维护者在真机上验过的版本标「已验证」，后面写着验证用的设备和 Android 版本。确认在 cccodroid 上有问题的版本会写明原因，选它之前会先问你。
- 渠道走到有已知问题的版本时，自动更新先不装它，你自己点更新照样可以装。
- 验证做了什么、没做什么，见 docs/claude-code-versions.zh-CN.md。

## 用订阅账户跑定时任务：默认关闭

- 用订阅账户（官方登录）跑的定时任务，现在默认不执行。要打开，去定时任务页底部的「订阅账户」，确认提示后打开：无人值守使用以 Anthropic 条款为准。用 API 密钥的接口不受影响。

## 其他

- 新增权限说明：每个权限拿来干什么、什么时候问、不给会怎样，见 docs/permissions.zh-CN.md。
- 网关加了自动化测试，每次打包前先跑。
